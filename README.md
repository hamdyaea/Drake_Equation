# Drake Equation Calculator

**Developer:** Hamdy Abou El Anein  
**Contact:** info@daylightlinux.ch  
**License:** See LICENSE.

A Python 3 model of the Drake equation, with editable assumptions and input validation. The defaults reproduce the original project's values. These are illustrative assumptions, not a scientific prediction.

```sh
python3 drake.py
python3 drake.py --star-formation-rate 2 --fraction-with-planets 0.8
python3 -m unittest discover -s tests -v
```

The original program is preserved on the [old branch](https://github.com/hamdyaea/Drake_Equation/tree/old).
